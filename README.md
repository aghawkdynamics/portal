# portal

AGHAWK Portal - Web-based service management portal.

## Applications

This repository includes:

- **Web Portal** (`/public`, `/src`, `/views`): PHP-based web application
- **Android App** (`/apps/android`): Native Android wrapper for the portal

### Android App

A native Android application that wraps the portal website in a WebView. Provides a seamless mobile experience with full feature support including:
- File uploads and downloads
- User authentication and sessions
- Theme persistence
- All web portal functionality

See [apps/android/README.md](apps/android/README.md) for build instructions and documentation.
